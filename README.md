# 🏫 校园问答小工具 (Campus Q&A)

一个零依赖的命令行校园问答小工具：根据用户输入的问题，通过**关键词匹配 + 模糊相似度**打分，从内置知识库中找出最匹配的答案。

## ✨ 功能特性

- **关键词加权匹配**：每个命中的关键词计 2 分
- **模糊相似度兜底**：用 `difflib` 计算整句相似度，支持"换个说法"的提问
- **综合打分排序**：关键词得分与相似度得分相加，取最高分条目返回
- **内置指令**：帮助、查看问题列表、退出
- **易扩展**：知识库以列表形式组织，追加一条记录即可新增问答

## 🚀 快速开始

无需安装任何第三方依赖，仅需 Python 3：

```bash
python3 campus_qa.py
```

运行后会出现提示符，直接输入问题即可：

```
你：图书馆几点开门？
小助手：📚 图书馆开放时间：周一至周五 8:00-22:00，周六周日 9:00-21:00，考试周延长至 23:00。
        （参考问题：图书馆的开放时间是什么时候？）
```

## 💬 内置指令

| 输入 | 作用 |
| --- | --- |
| `help` / `帮助` / `?` | 显示使用帮助 |
| `list` / `列表` / `问题列表` | 列出所有可回答的问题 |
| `exit` / `quit` / `退出` / `再见` | 结束程序 |
| `Ctrl+C` / `Ctrl+D` | 强制退出 |

## 🧩 扩展知识库

打开 [campus_qa.py](campus_qa.py)，在 `KNOWLEDGE` 列表中追加一条记录：

```python
KNOWLEDGE = [
    # (问题关键词列表, 标准问题, 答案)
    (["关键词1", "关键词2"], "标准问题？", "这里填写答案"),
    # ...
]
```

- **问题关键词列表**：用户提问中可能出现的词，命中越多得分越高
- **标准问题**：展示给用户的参考问题，同时参与整句相似度计算
- **答案**：最终返回给用户的回复内容

## ⚙️ 匹配算法说明

在 `find_answer()` 中，对每条知识库记录计算得分：

1. **关键词得分**：`2 分 / 每个命中的关键词`
2. **相似度得分**：`相似度比例 × 3 分`（最高 3 分）
3. 取总分最高的记录；若最高分低于阈值 `2`，则判定为"未匹配"，返回兜底提示

因此，命中 1 个关键词即可直接命中答案；仅靠句式相近也能被识别出来。
